Threads Downloader

Tempel tautan postingan Threads — sistem mengekstrak semua media: video dan gambar carousel, lengkap dengan username, foto profil, dan caption. Tanpa watermark.

NODE.JS EXAMPLE 
const res = await fetch('https://api.jhx.my.id/th-downloader', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'URL_THREADS_HERE' })
});
const json = await res.json();
if (json.Status) {
  json.data.media.forEach(m => console.log(m.type, m.url));
}
endpoints

POST /th-downloader — { url }

GET /resvid/:code.mp4 — proxy video

GET /resimg/:code.jpg — proxy image
