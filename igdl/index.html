Instagram Downloader

Tempel link Reels, Post, atau Story. Sistem mengekstrak seluruh media — video, foto, sampai audio — tanpa watermark, dalam hitungan detik.

✓ media siap diunduh

endpoint

POST /api/ig-downloader

body: { "url": "<instagram_url>" }
response: json → data.media[]

catatan
  • → Support Reels, Post carousel, dan Story publik.
  • → Hasil tanpa watermark, kualitas asli.
  • → Link unduhan aktif selama ±2 jam.
