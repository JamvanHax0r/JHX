~/modules/tk-downloader

TikTok Downloader

Tempel tautan TikTok — sistem mengekstrak video tanpa watermark (Normal & HD), slide foto, hingga video konversi slide, lengkap dengan metadata author & statistik.

DEVELOPER REFERENCE

Pakai Lewat Kode.

POST/tk-downloader
curl -X POST https://api.jhx.my.id/tk-downloader \
  -H "Content-Type: application/json" \
  -d '{"url":"URL_TIKTOK_HERE"}'

NODE.JS EXAMPLE 
const res = await fetch('https://api.jhx.my.id/tk-downloader', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'URL_TIKTOK_HERE' })
});
const json = await res.json();
if (json.Status) {
  const hd = json.data.variants.find(v => v.quality === 'HD');
  console.log(hd ? hd.url : json.data.variants[0].url);
}
endpoints

POST /tk-downloader — { url }

GET /resvid/:code.mp4 — proxy video

GET /resimg/:code.jpg — proxy image
