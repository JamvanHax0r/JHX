Spotify Downloader

Ketik judul lagu untuk mencari, atau tempel tautan track Spotify untuk langsung mengunduh MP3 kualitas penuh — lengkap dengan cover dan metadata.

HASIL PENCARIAN

⏳ link unduhan aktif ±5 menit

DEVELOPER REFERENCE

Pakai Lewat Kode.

POST/sp-search
curl -X POST https://api.jhx.my.id/sp-search \
  -H "Content-Type: application/json" \
  -d '{"q":"QUERY_HERE"}'
POST/sp-download
curl -X POST https://api.jhx.my.id/sp-download \
  -H "Content-Type: application/json" \
  -d '{"url":"URL_TRACK_HERE"}'

NODE.JS EXAMPLE 
const search = await fetch('https://api.jhx.my.id/sp-search', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ q: 'QUERY_HERE' })
}).then(r => r.json());

const track = search.data[0];

const dl = await fetch('https://api.jhx.my.id/sp-download', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: track.url })
}).then(r => r.json());

console.log(dl.data.url);
endpoints

POST /sp-search — { q }

POST /sp-download — { url }

GET /resvid/:code.mp3 — proxy audio

catatan
  • → Input fleksibel: kata kunci pencarian atau URL track.
  • → Proses verifikasi anti-spam memakan waktu ±10-30 detik.
  • → Link unduhan berumur ±5 menit — segera simpan.
