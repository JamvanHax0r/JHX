~/modules/fb-downloader

Facebook Downloader

Tempel link video Facebook (Reels, Watch, Post). Sistem mengekstrak video kualitas HD & SD tanpa watermark, lengkap dengan caption & author. Download langsung dalam hitungan detik.

DEVELOPER REFERENCE

Pakai Lewat Kode.

POST/fb-downloader
curl -X POST https://api.jhx.my.id/fb-downloader \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.facebook.com/share/r/..."}'
RESPONSE · 200 OK 
{
  "Developer": "JH a.k.a Dhika",
  "Kesayangan": "Fiony Alveria♡",
  "Status": true,
  "type": "download",
  "data": {
    "caption": "Video caption here",
    "author": "Author Name",
    "media": [
      { "quality": "HD", "size": "5.92 MB", "url": "..." }
    ]
  }
}
NODE.JS EXAMPLE 
const res = await fetch('https://api.jhx.my.id/fb-downloader', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'https://www.facebook.com/share/r/...' })
});
const json = await res.json();
if (json.Status) {
  json.data.media.forEach(m => console.log(m.quality, m.url));
}
endpoints

POST /fb-downloader — { url }

GET /resvid/:code.mp4 — proxy video (range supported)
