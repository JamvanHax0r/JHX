Lyrics Finder

Ketik judul lagu atau nama artis — JH Lyrics Engine menemukan lagu beserta lirik lengkapnya, dirapikan dengan formatting premium. Salin atau simpan sebagai .txt.

DEVELOPER REFERENCE

Pakai Lewat Kode.

POST/lyrics-search
curl -X POST https://api.jhx.my.id/lyrics-search \
  -H "Content-Type: application/json" \
  -d '{"q":"QUERY_HERE"}'
POST/lyrics-detail
curl -X POST https://api.jhx.my.id/lyrics-detail \
  -H "Content-Type: application/json" \
  -d '{"q":"SONG_ID_OR_SLUG_HERE"}'

NODE.JS EXAMPLE 
const search = await fetch('https://api.jhx.my.id/lyrics-search', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ q: 'QUERY_HERE' })
}).then(r => r.json());

const detail = await fetch('https://api.jhx.my.id/lyrics-detail', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ q: search.data[0].id })
}).then(r => r.json());

console.log(detail.data.lyrics);
endpoints

POST /lyrics-detail — { q: id/slug }
