Pinterest Downloader

Cari pin dari keyword, atau tempel link pin.it / pinterest.com. Sistem mengekstrak media — image kualitas originals atau video kualitas terbaik — tanpa watermark, dalam hitungan detik.

✓ pin siap diunduh

● VIDEO

✓ media siap diunduh

DEVELOPER REFERENCE

Pakai Lewat Kode.

POST/pin-search
curl -X POST https://api.jhx.my.id/pin-search \
  -H "Content-Type: application/json" \
  -d '{"q":"Fiony JKT48","limit":12}'
POST/pin-download
curl -X POST https://api.jhx.my.id/pin-download \
  -H "Content-Type: application/json" \
  -d '{"url":"https://pin.it/..."}'

NODE.JS EXAMPLE 
const res = await fetch('https://api.jhx.my.id/pin-download', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'https://pin.it/...' })
});
const json = await res.json();
if (json.Status) {
  console.log(json.data.url);
}
endpoints

POST /pin-search — { q, limit }

POST /pin-download — { url }

GET /resimg/:code.jpg — proxy image

GET /resvid/:code.mp4 — proxy video (range supported)

catatan
  • → Support shortlink pin.it dan URL pinterest.com/pin/…
  • → Video otomatis pilih kualitas terbaik (1080p → 480p).
  • → Image diprioritaskan resolusi originals / 736x.
  • → Link unduhan aktif selama ±1 jam.
