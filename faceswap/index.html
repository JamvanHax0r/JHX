DEVELOPER REFERENCE

Pakai Lewat Kode.

POST/faceswap
curl -X POST https://api.jhx.my.id/faceswap \
  -H "Content-Type: application/json" \
  -d '{
    "target": "https://i.top4top.io/p_3871i11ls0.jpg",
    "swap": "https://j.top4top.io/p_3871f5uoh0.jpg"
  }'
RESPONSE · 200 OK 
{
  "author_skrep": "JH a.k.a Dhika",
  "status": true,
  "data": {
    "url": "https://api.jhx.my.id/resimg/J7K2.jpg",
    "filename": "JHSwap_J7K2.jpg"
  }
}
PYTHON EXAMPLE 
import requests

res = requests.post(
    'https://api.jhx.my.id/faceswap',
    json={
        'target': 'https://i.top4top.io/p_3871i11ls0.jpg',
        'swap': 'https://j.top4top.io/p_3871f5uoh0.jpg'
    }
)
print(res.json())

PROCESS TIME
~30-60 detik

URL FORMAT
Harus berakhiran .jpg/.png
