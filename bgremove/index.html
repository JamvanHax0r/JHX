Pakai Lewat Kode.

POST/bg-remove
curl -X POST https://api.jhx.my.id/bg-remove \
  -H "Content-Type: application/json" \
  -d '{"url":"IMAGE_URL_HERE"}'

NODE.JS EXAMPLE 
const res = await fetch('https://api.jhx.my.id/bg-remove', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'IMAGE_URL_HERE', bg: '' })
}).then(r => r.json());

console.log(res.data.url);
endpoints

POST /bg-remove — { b64|url, bg?, type? }
