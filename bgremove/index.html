Background Remover

Hapus background foto otomatis dalam hitungan detik — hasil PNG transparan resolusi penuh, siap dipakai buat desain, olshop, atau editanmu.

Pakai Lewat Kode.

POST/bg-remove
curl -X POST https://api.jhx.my.id/bg-remove \
  -H "Content-Type: application/json" \
  -d '{"url":"IMAGE_URL_HERE"}'

NODE.JS EXAMPLE 
const res = await fetch('https://api.jhx.my.id/bg-remove', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'IMAGE_URL_HERE' })
}).then(r => r.json());

console.log(res.data.url);
endpoints

POST /bg-remove — { b64|url }

GET /resimg/:code.png — proxy hasil

catatan
  • → Support JPG/PNG/WebP, maksimal 8MB.
