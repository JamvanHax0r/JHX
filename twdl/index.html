~/modules/tw-downloader

Twitter / X Downloader

Tempel link tweet atau status X. Sistem mengekstrak video dalam semua kualitas, foto, sampai caption — tanpa watermark. Klik card untuk preview, pilih kualitas sesukamu.

NODE.JS EXAMPLE 
const res = await fetch('https://api.jhx.my.id/tw-downloader', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'URL_TWEET_HERE' })
});
const json = await res.json();
if (json.Status) {
  json.data.media.forEach(m => {
    if (m.type === 'video') console.log(m.variants[0].url);
    else console.log(m.url);
  });
}
endpoints

POST /tw-downloader — { url }

GET /resvid/:code.mp4 — proxy video

GET /resimg/:code.jpg — proxy image
