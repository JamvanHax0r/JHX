// Pertanyaan Umum

YANG SERING DITANYAKAN

Jawaban singkat sebelum Anda mulai pakai.

Apakah JH-Tools benar-benar gratis?

Ya. Semua modul inti bisa diakses tanpa biaya dan tanpa kartu kredit. Ke depannya mungkin ada tier tambahan untuk kebutuhan skala besar, tapi fungsi utama tetap gratis.

Bagaimana JH-Tools menjaga data pengguna?

Setiap request diproses lalu dibuang — kami tidak menyimpan file atau input Anda setelah sesi selesai. Koneksi ke server juga terenkripsi secara end-to-end.

Apa saja yang dibutuhkan untuk mulai pakai?

Tidak ada instalasi. Buka dashboard dari browser mana pun, pilih modul, dan langsung jalankan. Untuk pemakaian lewat kode, tersedia akses API di menu Dev Mode.

Ke mana saya bisa laporkan bug atau minta modul baru?

Lewat repository di GitHub (tombol Source Code di bagian atas) atau hubungi tim langsung dari tombol "Hubungi Tim" di bawah. Masukan dari pengguna langsung memengaruhi prioritas pengembangan.
