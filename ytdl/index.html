YouTube Downloader

Cari video YouTube atau tempel tautan langsung. pilih kualitas video atau ekstrak audio MP3, semua tanpa watermark.

DEVELOPER REFERENCE

Pakai Lewat Kode.

POST/yt-search
curl -X POST https://api.jhx.my.id/yt-search \
  -H "Content-Type: application/json" \
  -d '{"q":"QUERY_HERE"}'
POST/yt-download
curl -X POST https://api.jhx.my.id/yt-download \
  -H "Content-Type: application/json" \
  -d '{"url":"URL_YT_HERE","format":"720"}'

NODE.JS EXAMPLE 
const search = await fetch('https://api.jhx.my.id/yt-search', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ q: 'QUERY_HERE' })
}).then(r => r.json());

const dl = await fetch('https://api.jhx.my.id/yt-download', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: search.data[0].url, format: '720' })
}).then(r => r.json());

console.log(dl.data.url);
endpoints

POST /yt-search — { q }

POST /yt-download — { url, format }

GET /resvid/:code.mp4 — proxy video

GET /resaud/:code.mp3 — proxy audio
